# Complemento ES-DE anterior (archivado)

Este tema se preparó para EmulationStation dentro de PS5 RetroArch. Se conserva como referencia del diseño de cartuchos y portadas, pero **no forma parte del siguiente release**: depende de RetroArch y no es una aplicación PS5NES autónoma.

La arquitectura actual es una app homebrew con ejecutable propio, core NES enlazado directamente y directorios de usuario propios. Consulta [`../standalone/README.md`](../standalone/README.md).

El ZIP `PS5NES-ES-DE-v0.2.0-beta.1.zip` creado antes de este cambio corresponde solo al tema archivado. No lo presentes como el emulador independiente.
