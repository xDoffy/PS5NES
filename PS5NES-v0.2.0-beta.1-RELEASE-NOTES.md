# PS5NES v0.2.0-beta.1 — Integración con EmulationStation

- Añade el tema PS5NES para EmulationStation con carrusel de cartuchos NES.
- Usa las carátulas disponibles en la biblioteca de PS5 RetroArch como etiquetas de cartucho y muestra la imagen de consola elegida por el autor como fondo semitransparente.
- Permite lanzar desde EmulationStation los juegos de la lista NES con la configuración de sistema y el core FCEUmm de una instalación compatible de PS5 RetroArch.
- Incluye instrucciones de instalación, ruta de contenido y límites conocidos.

## Requisitos y límites

Este paquete es un complemento de tema, no un `.pkg` independiente. Requiere PS5 RetroArch con EmulationStation y FCEUmm instalados por separado. No incluye ROMs, BIOS ni el core. Las carátulas deben estar presentes en la biblioteca; el tema no las descarga por sí mismo.

La compatibilidad con firmware PS5 12.40 no ha sido verificada en consola. El formato `.zip` para ROMs tampoco se da por confirmado; usa archivos `.nes` sin comprimir para esta versión.
